# AutoVerse — Smart Car Showroom & Rental Platform

A real-world inspired dark automotive showroom built with React + Vite, React Router, Axios and JSON Server.

## Included
- Full-screen dark automotive hero with local hero image
- Interactive budget zones: ₹4–6L, ₹6–9L, ₹9–13L, ₹13–20L+
- Explore page with 47 cars
- 15+ SUV choices and everyday/basic cars
- Jaguar collection including F-Type, XE, XF, F-Pace, E-Pace and I-Pace
- Search, brand, body-style, fuel, transmission and budget filters
- Purchase-price and rental-price sorting
- My Dream Garage wishlist
- Add/Edit/Delete car CRUD
- Rental for a few days or multiple months
- Automatic rental total calculation
- My Rentals booking history
- Login and Signup using JSON Server
- Responsive mobile navigation

## Run

```bash
npm install
```

Terminal 1:

```bash
npm run server
```

Terminal 2:

```bash
npm run dev
```

Open the Vite URL shown in the terminal (normally http://localhost:5173).
